# LA Helper · 线性代数本地学习计算器

一个 **100% 本地运行** 的开源小工具，帮你在学线性代数时“不仅算出结果，还能看懂过程”。
所有矩阵运算使用 SymPy **精确有理数**，所以 `1/3` 永远不会变成 `0.333`。

## 功能
- 矩阵输入 / 展示、转置、加减、标量乘
- **矩阵乘法**（≤16×16，自动维度校验）
- **方阵求逆**（Gauss-Jordan，带步骤）
- **左逆 / 右逆**（满列秩 / 满行秩时给出；不满秩时说明原因）
- **Moore-Penrose 伪逆**（通用）
- **LU 分解**（含部分主元，PA = LU，带步骤）
- **增广矩阵求解**（[A|b] → RREF，判定唯一解 / 无解 / 无穷多解）
- **行列式、秩、RREF**
- **特征值 / 特征向量**（精确）
- 所有运算可**开关“显示步骤”**

## 快速开始
```bash
pip install sympy
python web/app.py        # 自动打开浏览器到 http://localhost:8000
```
无需联网、无需账号。

## 工程结构
```
la-helper/
├── core/          # 纯算法层（精确有理数，零 Web 依赖，全可单测）
├── web/           # 本地网页：app.py 起服务 + index.html / app.js
└── tests/         # pytest，TDD 红绿重构
```
- 算法与界面解耦：`core` 只算，`web` 只展示。
- 数值默认精确分数，可在界面切换小数显示。
